# Las Tajemnic theme

Theme of **Stowarzyszenie Larpowe „Las Tajemnic”** only. Other groups using this
project should create their own theme (`php bin/console app:theme:create <name>`)
instead of editing this one. Extends `base` — read `themes/base/README.md` first.

## Concept

*Las Tajemnic* (Forest of Secrets) at night, where the three kinds of worlds the group
plays in meet:

| World | LARPs | Visual language |
|---|---|---|
| Fantasy | Pradawne Zwoje, Czasy Pogardy, Wyprawa Rycerska | Cinzel carved headings, amber rune diamonds, glowing rune stones |
| Futuristic | Cybercrush | angled "terminal" buttons, HUD corner brackets, neon cyan/magenta edges on the hero title, ringed moon, Rajdhani UI font |
| Post-apo | Vault 47 | "radioactive moss" green as the primary colour, ruined radio tower with a blinking light, scanlines |

## Files

| File | What to change there |
|---|---|
| `assets/styles/tokens.css` | palette and fonts — start here |
| `assets/styles/fonts.css` | `@font-face` for the self-hosted fonts in `assets/fonts/` (SIL OFL) |
| `assets/styles/components.css` | buttons, cards (HUD corners), headings, badges, footer rule |
| `assets/styles/effects.css` | scanlines, title flicker, floating motes, reveal-on-scroll |
| `assets/scripts/effects.js` | adds motes (fireflies / embers / data sparks) to heroes; reveal on scroll |
| `assets/images/hero.svg` | default hero illustration (night forest, ringed moon, tower, rune stones) |
| `assets/images/card-placeholder.svg` | cover for LARPs without an uploaded image |
| `assets/images/logo.svg`, `favicon.svg` | logo: pine in a rune ring with a circuit node |

The SVGs were generated by a script (pine silhouettes, stars); they're plain SVG and
can be edited by hand or replaced. Their animations stop for visitors who prefer
reduced motion.

## Using real photos

The illustration is only a fallback. Upload a photo in the hero block's settings (or a
cover on the LARP the hero features) and it replaces the illustration; the dark
gradient overlay keeps the headline readable. Recommended: landscape, ≥ 1920 px wide,
subject on the right (the text sits on the left).
